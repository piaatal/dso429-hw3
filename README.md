# DSO 429 — Homework 3: The Hourly Quiz

Answers to the hourly quiz at
[FaisalXL/dso429-hourly-quiz](https://github.com/FaisalXL/dso429-hourly-quiz).

One file per round in `answers/`, named `round-NNNN.json` with the round number
padded to four digits:

```json
{ "round_id": 1, "answers": { "q1": "C", "q2": "A", "...": "..." } }
```

## Layout

- `answers/` — one JSON file per answered round (what gets graded)
